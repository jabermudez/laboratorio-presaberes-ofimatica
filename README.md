# Laboratorio de presaberes: Ofimática, TIC e IA

Instructor José Alexander Bermudez.

Autodiagnóstico inicial para un curso de 50 horas. 24 actividades en 8 estaciones; duración orientativa de 40 minutos. Incluye clasificación de tarjetas, secuencias de acciones, decisiones de caso, verdadero/falso e inspección de respuestas de IA.

## Aplicación

Abrir `index.html` o la dirección publicada en GitHub Pages. Todo el CSS, JavaScript, SVG y jsPDF están integrados en el HTML. No requiere backend ni descargas externas para evaluar y generar el PDF.

Los aprendices ingresan nombre e identificación y descargan su informe. Los datos permanecen en memoria durante la sesión; no se envían al repositorio ni a servidores y se borran al recargar. El instructor recoge los PDF por el medio acordado.

El contador avisa al cumplirse 40 minutos, pero permite terminar sin perder respuestas. El tiempo no afecta los puntos. Los resultados son formativos, sin nota de aprobación.

## Publicación

GitHub Pages, rama `main`, carpeta raíz. Solo `index.html` es necesario para ejecutar la aplicación. `.nojekyll` evita procesamiento adicional.

## Créditos

jsPDF 4.2.1 está integrado bajo licencia MIT; su aviso de licencia se conserva dentro del HTML. Diseño, preguntas y actividades originales del laboratorio. TIC e IA son extensiones didácticas solicitadas para el curso.
